# AGENTS.md

Reglas para cualquier agente que trabaje en este repo. El contexto vive en `CLAUDE.md`: leelo antes
de tocar nada (proyecto, stack, convenciones, variables de entorno y decisiones). Si difieren, manda `CLAUDE.md`.

- No levantar servidores locales. Los cambios se verifican deployando a Vercel.
- Nunca commitear `.env` ni credenciales, ni mostrar el valor de una variable de entorno.
- Mantener `CLAUDE.md` al día mientras se construye. Este archivo no duplica su contenido.
- Estándares y decisiones de la agencia: `RUBRA-OS/AGENTS.md`.
